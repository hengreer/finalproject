Shop Website

For my final project, I developed a shop website concept for ForgedFit Gyms, a local business owned by my partner.

The website features a homepage, product presentation, navigation, user registration and login. Once logged in, users can access their account, view their saved delivery addresses and submit new addresses through a form. The website also includes a contact form and links to its terms and conditions and privacy policy.

The project demonstrates the web development techniques covered during the module, including HTML, CSS, JavaScript, Bootstrap, form validation and API integration. I used the FreeAPI service to handle account authentication and retrieve and submit address data. The contact form uses Formspree to handle submissions.

Rather than implementing a complete e-commerce checkout, I focused on account management and address handling to demonstrate how a web application can collect user input, communicate with external services and display returned data.

Design Choices

I used the colours and visual style of the existing ForgedFit Gyms website to maintain consistent branding.

I combined Bootstrap with custom CSS to create a responsive layout for desktop and mobile screens. Bootstrap handles some layout and styling, while custom CSS controls the branding and appearance.
