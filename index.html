Shop Website

For My final project, I have created a shop website for my partner's local business, ForgedFit Gyms.

The website will not actually allow you to purchase products nor store any information. It will allow you to browse the products, add to a cart, and then "checkout". This will then send a confirmation email to the address you provide.


Design Choices

I have used the same themes and colours as the main ForgedFit website to keep branding consistent.

I have used a combination of Bootstrap and custom CSS to create a responsive design that works well on both desktop and mobile devices.
